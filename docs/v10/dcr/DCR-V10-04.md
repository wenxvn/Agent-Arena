- 状态：`accepted_by_agent`（`agent_reviewed`；V9 DCR-11 的 `requires_user_decision` 由 V10 提纲授权裁定，不是 `human_approved`）
- 地图：MAP-15 会变化的迷宫（金字塔 / 困难）
- 关联：`docs/v9/maps/MAP-15-audit.md`、`docs/v9/dcr/DCR-11.md`
- 规则版本：V8 `rule_hash=7d8322b90d7c67cf77d8cd39bc98bc8327c56097de34c5ffa35310fa3cf12e4f`（`scenario_v8/maps/map15.py`，只读） → V10 `rule_hash=0222e338ddf18bfdd271a28fbc7e50bf92c8616832c6f8564a4e5f630ab38030`（`v10/runtime/map15.py`，`RULE_VERSION=v10.map15.1`）
- 指标：V8 `metric_schema_hash=5294368961d55a133851ae06f72438a2b6ea9cab0a233795436af1e9e8173f44` → V10 `metric_hash=b04f8160cda8cfe6ecacf724a82c302b065907f377f6368cc4b80666a5953f87`
- 影响面：规则（相位自愈、错误成本、目标色规律）/ 公开信息（删除 goal 泄露）/ 动作集（`record_rule`、`predict_transition`）/ 指标 / 实例 seed

## 1. 原始规则（V8，只读）

- 规则本身写在 system prompt 与 `goal` 里（“从 A/B/C 归纳‘偶数同色、奇数互补’的规则”），所谓“归纳”在公开面上已经给出。
- 相位随每次选门翻转：选错 → 推进 1 tick → 相位翻转 → 同区按墙色（偶数相位）必然命中。**错误被相位翻转自动修复**（V9 §失败链：5 次奇数相位误判全部在下一步自动命中）。
- `no_rule_transfer`（只选墙色 + 错后重试）在 13 步内通关，说明规则迁移不是必需。

## 2. 证据与根因

- 事实：V9 三局 `loop_states` 全 0，因为每个 `(area, parity)` 只错一次；错误零成本自愈。
- 事实：`goal` 文本直接复述了变化规则，模型不需要从样例推断。
- 事实：随机基线（`legal_random` 5/20）也能通关，说明“相位翻转 → 同槽命中”提供了免费自愈。
- 根因：A 规则（错误推进 tick 导致相位翻转自愈）+ B 公开信息（goal 泄露规则）+ 缺乏“必须提交规则假设”的合法动作。

## 3. 方案

| 方案 | 改动 | 是否改变构念 |
|---|---|---|
| A（采用） | 删除 goal/prompt 中的规则描述；6 个规律家族 × 10 seed；训练墙色与测试墙色不重叠；测试区选错不推进 tick；新增 `record_rule`（提交假设）与 `predict_transition`（预测） | 否：恢复“从样例归纳变化规则”的原意 |
| B | 只删 goal 文本，保留相位自愈 | 不解决“错误零成本”“固定路径背答案” |
| C | 增加“多点一次按钮”式动作 | 把探索成本误当推理能力 |

## 4. V10 规则

1. **规律**：目标门色 = 墙色沿公开色环 `red → gold → blue → green → red` 前进 `offset[tick mod period]` 格。`period ∈ {2,3}`、`offsets` 隐藏，由环境 seed 选定的家族决定。共 6 个家族：

| 家族 | period | offsets | 预登记 seed |
|---|---:|---|---|
| `parity_complement` | 2 | (0,2) | 0, 6 |
| `parity_next` | 2 | (0,1) | 1, 8 |
| `parity_prev` | 2 | (0,3) | 3 |
| `parity_inverted` | 2 | (2,0) | 4, 9 |
| `triad_step` | 3 | (0,1,3) | 2, 7 |
| `triad_back` | 3 | (0,2,1) | 5 |

   **公开规则不再泄露周期或偏移**，只公开色环、周期取值范围（2/3）、偏移取值范围（0–3）与“规律在所有区相同”。
2. **训练/测试分离**：每个 seed 的色环被洗牌；训练区 A/B/C 只用两种墙色，测试区 T1/T2 使用训练中**从未出现**的另两种墙色。训练区每次选门（对或错）都追加一条 `training_sample_log` 样例；预置 2 条往期档案样例（连续 2 tick）。
3. **进入测试区前必须 `record_rule`**：`rule_id` 格式 `period=P;offsets=k0,k1[,k2]`，环境只校验格式与 `supporting_sample_ids` 是否引用合法样例，**不反馈对错**。
4. **消除相位自愈**：训练区选错耗 1 tick、留在原区；测试区选错**不推进 tick**（相位不变）、扣 1 次容错，共 2 次错误即 `TEST_WRONG_LIMIT` 失败；测试区内 `wait` 被拒且不推进 tick。V8 “错一次 → 相位翻转 → 同槽必中”的自愈被彻底删除。
5. `predict_transition(answer)` 在测试区可选、不耗 tick，单独计分。
6. 合法动作：`inspect_symbols`（不耗 tick，显示当前区墙色与各门颜色）、`choose_door(slot_index)`、`record_rule`、`predict_transition`、`wait`。

## 5. 预期构念影响

- “归纳”从公开面移回样例：模型必须从 `training_sample_log` 推断周期与偏移，再迁移到**未见过的墙色**上。
- 错误不再零成本：测试区两次错误即失败，`no_probe` / `random_rule` / `no_transfer` 都会明显受损。
- 合法动作 `record_rule` 使“提交假设”可观察，且与“多点一次按钮”不同——它要求格式化的假设，并被 `rule_generalization` 单独计分。
- 保留合法失败：训练区探索代价、测试区两次错误、假设格式错误。

## 8. 反例测试（`tests/test_v10_batch2.py`）

- `goal` / 公开规则不含“互补”“偶数”，也不含家族 `rule_id`；
- 6 个家族全覆盖 10 seed，训练墙色与测试墙色不相交（测试区要求迁移）；
- 测试区选错不翻转相位、可重复同一错误，第 2 次错误 → `TEST_WRONG_LIMIT`；
- 进入 C 后未 `record_rule` 直接选门 → `RULE_RECORD_REQUIRED`；格式错误 → `RULE_FORMAT_INVALID`；
- 归纳启发式（枚举 80 个假设用样例过滤）在 10 seed 上 10/10 成功且 `rule_generalization == 1`；四消融（`no_probe`/`fixed_route`/`random_rule`/`no_transfer`）每项 ≤ 1/10 成功；Oracle 10/10 且机制触发 10/10。

## 9. 对照结果（`python -m agent_arena.v10.baselines.suite MAP-15`）

| 策略 | 成功 | 主指标均值（首答准确率） | 说明 |
|---|---:|---:|---|
| Oracle（知道家族） | 10/10 | 1.0 | 机制触发 10/10 |
| public_heuristic（假设枚举 + 样例过滤 + 证据分割） | 10/10 | 1.0 | `rule_generalization` 全 1 |
| no_probe（不看样例，每区选 1 号门） | 0/10 | 0.25 | 从不 inspect |
| fixed_route（照搬 seed 0 槽位） | 1/10 | 0.3333 | 单一固定路径无法迁移 |
| random_rule（格式合法的随机假设） | 0/10 | 0.3333 | 假设与真家族无关 |
| no_transfer（假设 offset 恒 0） | 0/10 | 0.0 | 不做相位迁移 |
| legal_random（10 seed × 20） | 0/200 | N/A | 从未记录合法规则 |

`fixed_route` 的 1/10 是合法残留：seed 0 自身的槽位序列在其家族上正确；其余 9 个 seed 全部失败，证明“背答案”不可迁移。`3/3 success` 不再是验证依据。
