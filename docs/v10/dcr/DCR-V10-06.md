## 2. 原状与根因（V9 证据）

- MAP-28：机制本身有效（观察→记录→提交不可压缩，`no_record` 0/4），但 `person_id` / `entry_path_id` 合法枚举只存在于实现里（`map28.py:127-128`），Observation 只出现 `Celine`/`Basil` 与边 ID `S_V`，策略只能盲试；`timeline_constraint_satisfaction` 在未提交的终局里恒 0/4，与“提交了但全错”不可区分。
- MAP-29：`compare_testimony` 的参数与返回值语义只存在于实现里（`map29.py:379-425`），Observation 不给合法语句/证据集合；四名 NPC 的角色与偏差固定，没有“部分真实”类别，也没有跨阶段依赖。
- 共同根因：B 公开信息不足（枚举/语义）+ A 规则单一实例（只有 seed 0 一个案卷）。

## 3. V10 规则

### 3.1 MAP-28（4 个预登记案卷 seed）

每个 seed 的人物、跨入路径、时间与**证据依赖图**都不同，不是只换名字：

| seed | case_label | 真值（密封） | 依赖图特点 |
|---|---|---|---|
| 0 | `instrument_first_misremembered_person` | CELINE / SECRET_S_V / 21:06 → 21:14 | 证词误记人物，路径与时间窗有效 |
| 1 | `guard_path_misremembered_person` | BASIL / GUARD_G_V / 22:31 → 22:47 | 证词误记人物；档案只给人物 |
| 2 | `missing_exit_log_honest_witness` | ADA / BANQUET_H_V / 23:12 → 23:26 | **仪器日志缺出口侧**，离开时刻只能靠物证 + 诚实证词 |
| 3 | `misremembered_path_trap` | CELINE / BANQUET_H_V / 20:44 → 21:02 | 证词把路径误记为 G；引用它支持路径即自相矛盾 |

公开：`persons`、`entry_paths`、`required_key_evidence`、以及“每栏 ≥2 种来源类别”“引用必须是已 `record` 的证据”“提交一次终局”。

新增**引用自洽**判定：某栏只要被**引用**的证据否决，即不计为满足（未被引用、但已记录的冲突证据只计入 `time_contradictions` 护栏）。失败码分三类：`EVIDENCE_MISSING`（引用未记录/未观察）、`CLAIM_CONTRADICTS_RECORDED_EVIDENCE`（误记）、`ACCUSATION_WITHOUT_TWO_SOURCES`（值可能对但来源类别 <2）；终局统一 `CASE_REJECTED`。

### 3.2 MAP-29（4 个预登记案卷 seed）

- 公开 `npc_labels`（**职业**）与 `npc_locations`；**不公开**谁记错、谁隐瞒、谁只听到声音——角色分配随 seed 轮换（seed 0：A 时间锚定、B 隐瞒地点；seed 1：A 隐瞒、B 时间锚定；seed 2：C 为部分真实；seed 3：A 只听到声音且档案需要先听声型）。
- 公开 `compare_testimony` 的合法输入集合与四个返回码：`INSUFFICIENT` / `CONTRADICTED_AND_EXPLAINED` / `TESTIMONY_PARTIALLY_SUPPORTED` / `TESTIMONY_CONSISTENT`。
- 新增**部分真实**类别（地点对、时刻错），并新增跨阶段依赖：seed 3 的档案交叉索引要求先听到声型（`ARCHIVE_NEEDS_PREREQ`）。
- 问询预算从 8 提到 **12**（角色轮换后固定 8 会迫使盲目试探；公开启发式实际用 8–9 问，`questions_used` 仍作为效率指标）。
- 指标拆开：`contradiction_detection_rate`（过程量）、`evidence_supported_testimony_ratio`（仅在提交时有分母）、`partial_truth_classified`（仅在案卷含部分真实证人时适用）。

## 5. 反例测试（`tests/test_v10_batch3.py`）

- 4 个案卷的 `scenario_hash` 与真值互不相同；Observation 与公开规则不含密封真值（时间、`truth`/`sealed` 标记）；
- MAP-29 的 Observation 不含任何角色偏差描述或角色 key（`故意隐瞒`/`时间锚定`/`time_anchored` 全部不出现）；角色分配随 seed 变化；
- MAP-28 引用未记录证据 → `EVIDENCE_MISSING`；MAP-29 未听声型直接查档案 → `ARCHIVE_NEEDS_PREREQ`（且重复询问不会绕过前提）；
- MAP-29 部分真实证人在被比对时判为 `TESTIMONY_PARTIALLY_SUPPORTED`，无部分真实证人的案卷该指标为 `NOT_APPLICABLE`。

### MAP-29（4 seed）

| 策略 | 成功 | 主指标均值（植入矛盾识别率） |
|---|---:|---:|
| Oracle | 4/4 | 0.5 |
