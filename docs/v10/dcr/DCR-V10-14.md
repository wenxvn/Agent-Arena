## 1. 原状与根因（V9 证据）

- 事实：山路 A-F-C（2+2）与桥路 A-B-C（1+1）成本接近，启发式**全程走山路**，14 决策成功，`replanning_latency`/`route_cost_ratio` 都是 N/A——“完全不走桥就不会遇到改路”。
- 事实：`replanning_latency` 对**任何非桥边移动**置位，R2 改路 0 次却报 `latency=1`（`route_cost_ratio=1.0` 证明它走的是最短路），是假阳性；而对死守旧桥（16 次失败移动）返回 None，方向完全相反。
- 根因：A 规则（山路不比桥路慢，改路可被回避）+ D 指标（定义与实现不一致、分母边界混用）。

## 2. V10 规则

1. **山路被拉长**：A-F 由 2 → 3、F-C 由 2 → 3（山路 6 tick vs 桥路 2 tick），桥路成为唯一“在截止前有富余”的路线；改走山路会明显消耗时间余量。
2. **封路时刻不可预知且随 seed 变化**：4/5/6/7（隐藏），`probe_bridge`（B，2 tick）可提前探测；断后**站在桥上不会被瞬杀**，而是被推回 A 并多耗 2 tick——保留“继续撞桥”的合法选择，让时间余量惩罚它。
3. **新增公开标记 `collapse_observed`**：当 Agent 在封路后位于 A/B/C 时置位，改路判定从此有明确起点。
4. **两条主指标重定义**（对 V9 的 `METRIC_DEFECT`）：
   - `replan_success`（primary）= **封路前用过桥路** 且 观察到封路 且 完成且未再尝试断边；若封路前没用桥路 → `NOT_APPLICABLE`（不能把“绕开桥”算成“改路成功”）；
   - `replan_latency`（secondary）= 观察封路后第一个移动 tick − 观察 tick；
   - 护栏 `collapsed_edge_attempts_after_observation` 与 `route_cost_ratio`（只在最短成本 > 0 时有分母）。
5. 4 个实例：封路时刻 4/5/6/7、潮汐相位 0/1/2/3、截止 18。
