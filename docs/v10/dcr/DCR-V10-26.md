# DCR-V10-26：截尾口径归一（五态 `CENSORED` 的系统性漏判）

- 状态：`accepted_by_agent`（`agent_reviewed`）
- 类型：**指标投影修复**（不改任何指标定义、公式、分母或规则）
- 影响面：`v10/baselines/runner.py`（离线基线投影）、`scripts/run_v10_mimo.py`（真实模型投影）、
  `v10/recompute.py`（复算基准）；地图文件与 `METRIC_SPECS` 未改，`metric_hash`/`rule_hash` 不变
- 发现路径：`python -m agent_arena.v10.recompute`（主指标公式级第二套实现）

## 1. 原状与根因

复算在 633 次检查中发现 **53 次不一致**，全部同一根因：

- 各图 `v10_metrics()` 的截尾判定只检查**环境**的 `step_limit_reached`
  （`running = self.status.value == "step_limit_reached"`）；
- V10 的真实截断来自 **runner 的决策预算**，此时环境停在 `running`、`is_terminal=False`；
- 于是被预算截断的局仍报 `VALID`（MAP-10 16 例、MAP-20 1 例、MAP-22 16 例、MAP-23 8 例）
  或 `NOT_APPLICABLE`（MAP-28 12 例），与规格里白纸黑字的「截尾 → CENSORED」冲突。

逐字证据（`runs/v10/recompute/metric_recompute.json` 的 `mismatches`）：

```
MAP-10 MAP-10-S0-no_move        | 地图 VALID 0           vs 独立 CENSORED
MAP-20 MAP-20-S2-bypass_overuse | 地图 VALID 0.388235    vs 独立 CENSORED
MAP-22 MAP-22-S0-no_return      | 地图 VALID 0           vs 独立 CENSORED
MAP-28 MAP-28-S0-random0        | 地图 NOT_APPLICABLE    vs 独立 CENSORED
```

这也解释了 `baselines` 里 `legal_random` 主指标均值长期为 `0.0` 而非 `null`：截断局被当成
“合法失败 0 分”计入了均值。

## 2. 修复内容

新增 `v10/metrics/governance.py::truncation_censored(map_id, metrics, *, truncated)`，
在**投影层**按规格已有文本归一（不改规格本身）：

1. 局被截断 且 规格 `censored_rule` 含「截尾 → CENSORED」且未含「部分进度保持 VALID」/「仍 VALID」
   → `VALID` 改判 `CENSORED`（MAP-10/19/20/22 等）；
2. 局被截断 且 规格 `zero_denominator` 含「截尾 → CENSORED」→ `NOT_APPLICABLE` 改判 `CENSORED`（MAP-28）；
3. 声明「部分进度保持 VALID」的指标**不动**（MAP-18 送达数、MAP-23 线索缩减、MAP-29/30 计数）。

调用点：`baselines/runner.run_policy`、`scripts/run_v10_mimo.py`、`recompute._replay`。

## 3. 对照与反例测试

- `tests/test_v10_batch9_truncation.py`（6 条）：截断 + 声明 CENSORED → CENSORED；部分进度 → 保持 VALID；
  `zero_denominator` 含截尾条款才把 N/A 改判；未截断 / V8 回退图 / 未注册指标一律不动。
- `tests/test_v10_batch3.py` 更新：MAP-30 `accusation_claim_precision` 在
  `late_guess`（截断）下为 `CENSORED`、在 `evidence_shuffle`（终局指控被拒）下为 `NOT_APPLICABLE`，
  两种终局各有一条断言（原先只断言后者，掩盖了截断漏判）。
- 复算：`python -m agent_arena.v10.recompute` 从 **53 处不一致 → 0 处**（633 次检查、17 张图）。

## 4. 迁移与影响

- 离线基线已重跑（`baselines.suite` 全 23 图），`legal_random`/消融在截断局的取值由
  `VALID 0` 变为 `CENSORED`（相应地 `*_primary_mean` 由 0.0 变为 `null` 或按已结算局计算）；
- **Batch 8 的 MiMo 逐局记录不回写**：它们是历史证据，逐局 manifest 里的取值与
  `metric_schema_hash` 保持不变；解释时必须知道“截断局的 VALID 0 是旧口径”；
- 回滚：删除三处调用即恢复旧行为（地图与规格文件本就没动）。
