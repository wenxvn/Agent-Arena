# V11 展示难度（design vs display）

- `design_difficulty` 保留 V8/V10 原始标签，不修改。
- `display_difficulty` 与 `difficulty_note` 只存在于展示层，不进入运行时、规则 hash、指标或历史 trace。
- 评估依据：动作链长度、公开规则数量、每 tick 约束、信息是否可得、人工阅读体验；**不按 MiMo 3 局胜率机械重排**。
- MAP-01～MAP-30 编号、世界顺序与规则 hash 均未改变。

## 与设计难度不同的图（人工可解释调整）

- **MAP-12 极夜三十天**：设计 困难 → 展示 中等。回合多（30 天）但每天只有三种劳动，认知负担低，主要是配平。
- **MAP-14 说谎的祭司**：设计 中等 → 展示 困难。说谎者逻辑题；最多 4 问、只能错交 1 次，推理强度高于设计标签。
- **MAP-16 单线预约与节点容量**：设计 简单 → 展示 中等。只有两列车，但 set_route 与 move_train 分帧提交，容易漏掉整帧语义。
- **MAP-17 早高峰**：设计 中等 → 展示 困难。四车时刻表 + 咽喉站容量，操作项多且冲突会整帧拒绝。
- **MAP-19 温度临界点**：设计 简单 → 展示 困难。规则不多，但每 tick 必须申报温度且冷却延迟两 tick，操作链明显长于设计标签。
- **MAP-20 冷却网络**：设计 中等 → 展示 困难。十条公开规则、有损旁路与区阀上限叠加，是本轮热控最难的一张。
- **MAP-22 无地图的丛林**：设计 简单 → 展示 中等。没有地图，需要自己记录路标并原路返回，空间记忆负担高。
- **MAP-25 第一次出舱**：设计 简单 → 展示 中等。九种工具、完整 EVA 流程；步骤多但每步都有明确前提。
- **MAP-28 消失的王冠**：设计 简单 → 展示 中等。四字段指控且每个字段要两类来源，结构严格但房间图很小。
- **MAP-29 不可靠的证人**：设计 中等 → 展示 困难。12 次提问内识别不可靠证人，还要给出可引用的物证链。

## 重点图的体验说明

- **MAP-19 温度临界点**：记住：读取温度、设置冷却、调负荷都不会推进时间，每个 tick 必须 wait 一次。
- **MAP-20 冷却网络**：记住：set_flow、旁路与负荷只改本 tick 设置，必须 wait 才结算；旁路只送到 4/5。
- **MAP-28 消失的王冠**：提交前检查：四个字段都要有至少两种不同来源类别的已记录证据。
- **MAP-29 不可靠的证人**：提问预算只有 12 次；先取物证再比对证词，能少走弯路。
- **MAP-30 午夜审判**：案卷条目需要“现场记录 + 证人确认”；近期动作窗口只保留最近 5 条。
