# V11 网页页面说明

启动：`uv run --with streamlit agent-arena web`（默认 `http://127.0.0.1:8501`）。

## 1. 导航

| 页面 | 用途 |
|---|---|
| 首页 / 地图大厅 | 十世界卡片、30 图筛选、快速离线演示 |
| 挑战配置 | 地图详情、seed、模式、Provider/模型、预算、开始 |
| 运行监控 | 状态、进度、预算、动作时间线、停止 |
| 结果与回放 | 终局、指标五态、逐步回放、导出 |
| 历史与对照 | 筛选、两局对照、本地同模型成绩榜 |
| 研究回放（只读） | 保留旧四视图：单局回放/矩阵总览/错误热点/条件对照 |
| 设置与帮助 | Provider 状态、连接检查、预算边界、错误解释、数据位置 |

导航状态只保存在 `st.session_state["nav"]`；**任务状态**始终来自 `runs/web` 的 manifest。

## 2. 首页 / 地图大厅

- 顶部 4 个指标：30 图、10 世界、离线 0 元、真实挑战需 API；
- “快速开始”按钮创建 MAP-01 / seed 0 的离线运行并跳到运行监控；
- 世界、展示难度、关键词筛选；
- 每张卡片显示：世界、MAP ID、标题、公开目标、机制、决策预算、工具数、设计/展示难度、难度说明；
- 卡片按钮“选择这张图”跳到配置页；
- 空状态：筛选无结果时提示，不渲染空白网格。

## 3. 挑战配置

- 地图下拉（30 图，显示世界与设计难度）；
- 环境 seed 下拉，只能选该图 `SEED_SPACE` 中登记的 seed；
- 详情折叠区：
  - 成功 / 失败 / 截尾说明；
  - 公开规则全文；
  - 带类型的动作契约；
  - 本图接口提醒（MAP-16/18/19/28）；
  - 公开观察字段与 `scenario_descriptor`；
  - 版本 hash（rule/metric/runtime/primary metric）。
- 执行模式：**默认离线演示（不花钱）**；切换真实模式后显示 Provider、模型、密钥状态、地址 host；
- 预算：决策、请求、输入 token、输出 token、费用上限；
- 真实模式必须勾选“我确认发送真实请求并接受可能产生的费用”；
- 开始前做零网络 `configuration_check`；配置不完整直接拒绝；
- 同一配置 + 同一 `submit_nonce` 使用相同 idempotency key，双击不会重复创建。

## 4. 运行监控

- 运行下拉（最近 30 局）；
- 自动刷新（`st.fragment(run_every="1.5s")`）可关闭；关闭后提供手动刷新；
- 状态徽章：成功/失败/预算耗尽/Provider 错误/取消/中断；
- 进度条、动作数/预算、请求数、输入输出 token（k 缩写）、费用；
- 未终态时显示“停止运行”，并提示停止在请求/步骤结束后生效；
- 动作时间线：步、工具、目标、结果、状态、token、理由；
- 终态显示“查看结果”；
- 页面刷新只读 manifest，不重新执行模型。

## 5. 结果与回放

- 运行选择、地图/标题/模式/模型/seed/开始时间；
- 状态徽章与失败解释（来自环境终止码与指标五态，不猜模型意图）；
- 动作数、非法动作、被拒动作、费用；
- 主指标与五态；
- 指标表：指标、五态（有效/截尾/不适用/缺失/非法）、值、单位、范围；公式在折叠区；
- P2：公开状态走势图（只画公开 Observation 中的数值字段，可切换）；
- 逐步回放：步骤滑块、动作 JSON、公开 Observation（折叠）；
- 导出：回放 JSON、摘要 JSON、逐动作 CSV（UTF-8 BOM）；
- 版本 hash：scenario/rule/metric/metric_schema/prompt；
- “用相同地图与 seed 再跑一局”跳到配置并递增 nonce。

**决策理由**：V10 `scenario_v4` 动作契约不返回 `decision_reason`，真实模式显示“—”；离线模式显示“公开启发式规则策略（离线演示，非模型决策）”。不伪造理由。

## 6. 历史与对照

- 筛选：地图、状态、模式、run_id/模型、起始日期；
- 表格：run_id、地图、标题、模型、seed、状态、结局、费用；
- 导出筛选结果 CSV；
- 两局对照：同地图 + 同 rule_hash + 同 metric_hash + 同 metric_schema_hash + 同模式才允许直接比较；模型不同/seed 不同给警告；
- 本地同模型成绩榜：同地图、同模型、同模式、同规则/指标版本内排序；显示 seed、预算差异；不是跨模型排名。

## 7. 设置与帮助

- Provider 状态表：OpenAI-compatible/MiMo、Ollama、离线演示；密钥只显示已配置/未配置；
- 连接检查：需要显式勾选，发送 1 次最小请求，可能产生极少量费用；
- 费用与预算边界：平台硬上限 JSON；
- 常见错误：缺 Key、连接失败、超时、限流、模型不存在、预算、未知；
- 日志与数据位置：`runs/web`，每局 manifest/events/result 可整体删除。

## 8. 研究回放（只读）

保留旧四视图，读取 `runs/`、`results/`，用于历史研究 trace 与 benchmark CSV。与 V11 运行记录互不影响。

## 9. 状态与响应式

- 完整状态：空状态、加载态（spinner）、错误态、成功/警告/信息徽章；
- 宽屏 3 列地图卡片；窄屏由 Streamlit 自动堆叠；
- 表格在窄屏横向滚动；页面没有 3D 或重型前端依赖；
- 主题跟随 Streamlit 深浅色；自定义 CSS 只调整卡片、间距与移动端 padding。
