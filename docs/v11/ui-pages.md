# V11 网页页面说明

启动：`uv sync --extra web` 后运行 `uv run agent-arena web`（默认 `http://127.0.0.1:8501`）。没有 extra 时可用 `uv run --with streamlit agent-arena web`。

## 0. 视觉与交互基线

页面样式集中在一个纯展示模块 `src/agent_arena/ui/theme.py`，不 import Streamlit，可单测：

- **设计令牌**：主色 `#4c6ef5`、成功 `#12a150`、警告 `#e08c1a`、危险 `#e5484d`、信息 `#2f80ed`；圆角 16px，浅色/深色都只用半透明叠色，因此两套主题都成立。
- **语气（tone）映射**：运行状态、展示难度、指标五态各有唯一映射，颜色只表达语义，不改变任何判定。
- **可复用片段**：页头（小标签 + 标题 + 说明）、统计块、徽章、横幅、进度条、空状态、键值块、地图卡片。
- **侧边栏**：品牌块 + 导航（选中项高亮）+ 当前运行摘要 + 版本脚注；窄屏由 `initial_sidebar_state="auto"` 默认收起。
- **响应式**：900px 以下压缩内边距与字号；430px 实测可用。
- 所有用户可见文本经 `html.escape` 转义，HTML 片段只由固定模板拼接。

## 1. 导航

| 页面 | 用途 |
|---|---|
| 首页 / 地图大厅 | 十世界卡片、30 图筛选与分页、快速开始 |
| 挑战配置 | 地图详情、seed、模式、Provider/模型、预算、开始 |
| 运行监控 | 状态、进度、预算、动作时间线、停止 |
| 结果与回放 | 终局、指标五态、状态走势、逐步回放、导出 |
| 历史与对照 | 汇总统计、筛选、两局以上对照、本地同模型成绩榜 |
| 研究回放（只读） | 保留旧四视图：单局回放/矩阵总览/错误热点/条件对照 |
| 设置与帮助 | Provider 状态、连接检查、预算边界、错误解释、数据位置 |

导航状态只保存在 `st.session_state["nav"]`；**任务状态**始终来自 `runs/web` 的 manifest。

## 2. 首页 / 地图大厅

- 页头：小标签 + 标题 + 一句话说明“默认离线演示：不花钱、不联网、不发任何请求”；
- 四个统计块：地图 30 / 世界 10 / 本地运行数与成功数（来自真实历史）/ 离线演示 0 元；
- 快速开始三张卡：离线演示（主按钮）、真实挑战、历史与对照，各自说明代价与边界；
- 地图大厅：世界 / 展示难度 / 关键词三列筛选；
- **每页 9 张卡片 + 上一页/下一页**，页码写在 URL 无关的 session 里；筛选条件变化时自动回到第 1 页；
- 每张卡片：MAP ID、世界、展示难度徽章、本地战绩（“已跑 N 局 · 成功 M”或“未跑过”）、标题、公开目标、机制/预算/工具/seed、设计难度与难度说明；
- 空状态：筛选无结果时给图标 + 标题 + 下一步建议，不渲染空白网格。

## 3. 挑战配置

- 地图下拉（30 图，显示世界与设计难度）；
- 环境 seed 下拉，只能选该图 `SEED_SPACE` 中登记的 seed；
- 左侧：MAP/世界/展示难度/设计难度/运行时徽章 + 标题 + 公开目标 + 四个统计块（决策预算、可用 seed、工具、公开规则条数）+ 难度说明；
- 右侧：seed 选择与该图专属提醒（如 MAP-19 的 wait 语义）；
- **公开信息分组为四个 tab**：公开规则（含成功/失败/截尾说明）、动作契约（带类型 + 本图接口提醒）、观察字段（公开字段 + `scenario_descriptor`）、版本与 hash；
- 执行模式：默认离线演示，切换真实模式后显示 Provider、模型、密钥状态、地址 host；
- 预算：决策上限（滑杆）、请求/token/费用上限，下方实时汇总“动作/预算、请求上限、token 上限、费用上限”；
- 真实模式必须勾选“我确认发送真实请求并接受可能产生的费用”；
- 开始前做零网络 `configuration_check`；配置不完整直接拒绝；
- 同一配置 + 同一 `submit_nonce` 使用相同 idempotency key，双击不会重复创建。

## 4. 运行监控

- 运行下拉（最近 30 局）；
- 自动刷新（`st.fragment(run_every="1.5s")`）可关闭；关闭后提供手动刷新；
- 状态徽章用横幅呈现：标题 + 终止码 + 说明；
- 进度条按状态着色（运行中蓝、成功绿、预算耗尽橙、失败红）；
- 四个统计块：动作数/预算、请求数、输入输出 token（k 缩写）、费用（未知消费显示“未知”）；
- 未终态时显示“停止运行”，并提示停止在请求/步骤结束后生效；终态显示“查看结果”；
- 动作时间线默认最近 20 条，可勾选“显示全部动作”；离线演示中全部相同的理由折叠为“同上”，避免重复长句；
- 页面刷新只读 manifest，不重新执行模型。

## 5. 结果与回放

- 运行选择；标题 + 模式/模型/seed/用时徽章；
- 结局横幅只由环境终止码与指标五态解释；**成功局不再显示“失败归因”**，改为“机制复核：…”，避免把成功读成失败；
- 四个统计块：动作数、非法动作、被拒动作、费用（0 非法动作用绿色，非 0 用红/橙）；
- 主指标一行：指标名 + 五态徽章 + 值；
- 指标表：指标、五态、值、单位、范围（`valid_range` 渲染为 `0.0 – 1.0`）；公式在折叠区；
- 公开状态走势：Altair 面积图，纵轴从数据范围开始（`zero=False`），横轴按整数步长标注；Altair 不可用时退回内置折线图；
- 逐步回放：步骤滑块 + 左右并排的“动作 / 公开 Observation”JSON + 折叠的完整时间线；
- 导出：四种格式放在一个带边框的区块内，并说明 CSV 带 UTF-8 BOM；
- 版本 hash 只显示前 16 位，完整值在折叠区；另有安全边界说明；
- “用相同地图与 seed 再跑一局”跳到配置并递增 nonce。

**决策理由**：V10 `scenario_v4` 动作契约不返回 `decision_reason`，真实模式不显示该列；离线模式显示“公开启发式规则策略（离线演示，非模型决策）”。不伪造理由。

## 6. 历史与对照

- 四个汇总统计块：本地运行、已完成、成功率、累计费用；
- 筛选：地图、状态、模式、Provider、seed、run_id/模型/标题、起始日期；
- 表格：run_id、地图、标题、模型、seed、状态、结局、动作/预算、费用；
- 行下方提供“打开某局的回放”下拉 + “打开结果”按钮（不再需要手动复制 run_id）与导出筛选 CSV；
- 多局对照：同地图 + 同 rule_hash + 同 metric_hash + 同 metric_schema_hash + 同模式才允许直接比较；模型/seed 不同给警告；
- 本地同模型成绩榜：同地图、同模型、同模式、同规则/指标版本内排序；显示 seed、预算差异；不是跨模型排名。

## 7. 设置与帮助

- Provider 状态表：[OI]-compatible/MiMo、Ollama、离线演示；密钥只显示已配置/未配置；
- 连接检查：需要显式勾选，发送 1 次最小请求，可能产生极少量费用；
- 费用与预算边界：平台硬上限 JSON；
- 常见错误：缺 Key、连接失败、超时、限流、模型不存在、预算、未知；
- 日志与数据位置：`runs/web`，每局 manifest/events/result 可整体删除。

## 8. 研究回放（只读）

保留旧四视图，读取 `runs/`、`results/`，用于历史研究 trace 与 benchmark CSV。与 V11 运行记录互不影响。

## 9. 状态与响应式

- 完整状态：空状态、加载态（spinner）、错误态、成功/警告/信息徽章；
- 宽屏 3 列地图卡片，窄屏自动堆叠；
- 深色模式跟随系统 / 浏览器，不需要单独维护第二套颜色；
- 页面没有 3D 或重型前端依赖，全部 CSS 在 `theme.py` 内联注入。
