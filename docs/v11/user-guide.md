# V11 用户指南

## 1. 一局挑战的完整流程

1. **选图**：首页按世界/展示难度/关键词筛选，点击“选择这张图”；
2. **看规则**：配置页展开“公开规则与动作契约”，确认目标、成功/失败条件、动作字段类型；
3. **选 seed**：只能选该图预登记的环境 seed；
4. **选模式**：默认离线演示；真实模式需要本机 `.env` 与显式费用确认；
5. **设预算**：决策上限、请求上限、输入/输出 token、费用上限；
6. **开始**：创建 `run_id`，进入运行监控；
7. **看过程**：状态、进度、动作时间线、公开 Observation；
8. **停止**：运行中可点“停止运行”，在当前请求/步骤结束后生效；
9. **看结果**：终局、失败解释、指标五态、版本 hash；
10. **回放/导出**：逐步回放、JSON、摘要 JSON、逐动作 CSV。

## 2. 离线演示与真实挑战的区别

| 项 | 离线演示 | 真实挑战 |
|---|---|---|
| Provider | 无 | OpenAI-compatible / Ollama |
| 决策者 | 公开启发式规则策略 | 模型 |
| 费用 | 0 | 可能产生 |
| 结果标注 | `public_heuristic_policy` | `v10_action_loop` + 模型名 |
| 用途 | 体验页面、验证回放与导出 | 真实模型行为 |

离线成功不代表模型能力；页面和结果都不会把规则策略写成模型结果。

## 3. 运行状态

| 状态 | 含义 |
|---|---|
| `CREATED` / `QUEUED` | 已创建 / 排队 |
| `RUNNING` | 正在执行 |
| `SUCCEEDED` | 环境返回成功 |
| `FAILED` | 环境判定失败 |
| `BUDGET_REACHED` | 决策/请求/token/费用/环境动作上限耗尽（截尾） |
| `CANCELLED` | 用户取消 |
| `PROVIDER_ERROR` | Provider 连接、超时、usage 缺失等，fail-closed |
| `INTERRUPTED` | 进程退出后恢复，保留部分记录 |

`CENSORED` 是**指标五态**之一，不是运行状态；页面分别显示。

## 4. 指标五态

| 五态 | 页面文案 | 处理 |
|---|---|---|
| `VALID` | 有效 | 正常显示值 |
| `CENSORED` | 截尾 | 显示“—”，不写 0 |
| `NOT_APPLICABLE` | 不适用 | 显示“—” |
| `MISSING` | 缺失 | 显示“—” |
| `INVALID` | 非法 | 显示“—”，并保留状态 |

主指标、单位、范围、公式都在结果页；公式在“指标公式”折叠区。

## 5. 决策理由

V10 的 `scenario_v4` 动作契约只返回动作，不返回 `decision_reason`。因此真实模式的时间线“理由”列显示“—”；离线模式显示“公开启发式规则策略（离线演示，非模型决策）”。V11 不拼接或猜测模型理由。

## 6. 历史与对照

- 按地图/状态/模式/模型/日期筛选；
- 两局对照只有在**同地图 + 同 rule_hash + 同 metric_hash + 同 metric_schema_hash + 同模式**时才允许直接比较；
- 模型不同或 seed 不同会给出警告；
- 本地同模型成绩榜只在同地图、同模型、同模式、同规则/指标版本内排序；
- 不是跨模型公平排名，也不上传到公网。

## 7. 导出

- **回放 JSON**：manifest、result、逐动作公开事件；
- **摘要 JSON**：result（不含 steps）；
- **逐动作 CSV**：UTF-8 BOM，Excel 可直接打开；字段固定、逐行动作；
- 导出不包含：API Key、隐藏世界真值、完整 system prompt、Provider 响应头/正文。

## 8. 停止与刷新

- 刷新页面不会重复执行；页面只读 manifest；
- 停止是协作式的，已经发出的 HTTP 请求不能强制中断；
- 进程崩溃后，重启网页会把遗留运行标为 `INTERRUPTED`，已写动作仍可回放；
- 重复点击“开始挑战”由 idempotency key 去重。

## 9. 研究回放

“研究回放（只读）”保留旧四视图，用于浏览 V3/V10 研究 trace 与 benchmark CSV。它不启动新实验、不读取 `.env`、不调用 Provider。

## 10. 已知限制

- 单机单用户；不支持公网、多用户、登录或云数据库；
- 真实模式不自动重试；失败需要用户手动再开一局（新 `run_id`）；
- 无模型决策理由（V10 契约限制）；
- 表格在窄屏需要横向滚动；
- macOS/Linux 启动说明已提供，但本次实际运行验证只在 Windows 11 完成。
