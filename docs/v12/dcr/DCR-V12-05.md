# DCR-V12-05：反思（Reflection）的公开触发器在本组地图上从未激活

- **状态**：`agent_reviewed`
- **严重度**：低（不影响已有结论，但使"反思是否提效"这一问题在本轮不可回答）
- **发现于**：附加对照 `v12-ablation-reflection-on/off`
  （`lab-20261026T040533Z-447523e3` / `lab-20261026T040534Z-2dd57d9e`）
- **类别**：测量配置 / 触发器阈值（不是环境缺陷、不是策略缺陷）

## 1. 事实

按提纲 §4.3-3 做 Reflection on/off 对照（MAP-16，seed 0/1，各 1 局）：

| seed | 开启：终态 | 关闭：终态 | 开启：决策 | 关闭：决策 | 开启：`reflection_triggered` | 关闭：`reflection_triggered` |
|---:|---|---|---:|---:|---:|---:|
| 0 | FAILED `DEADLOCK` | FAILED `DEADLOCK` | 6 | 6 | **0** | 0 |
| 1 | SUCCEEDED `GATE_OPENED` | SUCCEEDED `GATE_OPENED` | 14 | 14 | **0** | 0 |

两臂**结局、决策数完全一致**，且 `reflection_triggered` 事件数为 **0**。

## 2. 根因

`reflection.v1` 的触发器是纯公开规则（提纲 V12-06-01 要求）：

- 连续无进展 ≥ N 步（默认 5）
- 重复被拒动作 ≥ N 次（默认 3）
- 重复同一动作 ≥ N 次（默认 4）
- 空转（动作被接受但公开可观测量无变化）≥ N 次

MAP-16 的失败路径太短：seed 0 在第 **6** 步就以 `DEADLOCK` 终止，
seed 1 在第 14 步成功。两者都没有累积出任何一条达到阈值的公开信号，
因此反思没有被触发——**这不是反思无效，而是它没被叫醒**。

## 3. 后果

- "Reflection 是否带来净收益"在本轮**不可回答**；
- 报告必须写"触发器未激活"，不能写"反思无效果"；
- 这也说明：**反思的价值只在长失败前缀上才可测**，而这类前缀在六图里
  主要出现在 MAP-22（迷路，决策 40+）与 MAP-30（法庭流程，决策 100+）。

## 4. 处理

1. 本轮保留实验与结论，写明"未激活"；
2. 不调整阈值重跑——调阈值会改变被比较的变量，必须作为**新版本**另开实验；
3. V13 建议：把反思对照的适用地图显式限定为"失败前缀 ≥ 触发器阈值"的图，
   并在预检里给出"预计可触发图/seed"的估计。

## 5. 建议（V13）

- Registry 里给每个 Agent 增加 `applicable_when` 之类的前置说明，
  让预检能提示"该消融在当前地图上可能不触发"；
- 或者把反思触发阈值做成**实验规格的一部分**（与 prompt 版本一起冻结），
  在报告里显式列出，避免不同实验用不同阈值却混在一起比较。
