## 3. 读法（不许夸大）

- 每组只有 3 个环境 seed × 3 次重复；重复是**模型采样波动**，不是新环境样本。
- 两臂差异必须同时看成功率与成本；0 成功的条件下不得写“某策略更好”。
- `E3` 在 Pilot 中 `triggered = 0` → `NO_TREATMENT_EXPOSURE`，**不评价反思有效性**。
- 全部为 `LIVE` 单模型（MiMo）结果，不构成跨模型结论。
