## 3. 读法

- `route_recall` 上升说明路线被完整写进公开记忆（机制成立）；
- 若某 seed 的两臂在「平均折返 / 重复访问」上没有差别，说明该实例的失败不是「记不住路」，而是别的原因（例如目标顺序或遗迹判定）；
- 这张表只能给出**关联**，不能证明因果：样本来自同一个模型、同一批预算。
