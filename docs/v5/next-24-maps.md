# 其余 24 张地图的接入条件

本轮运行时与付费矩阵只覆盖 MAP-08、16、18、22、26、30。其余 24 张 V4 地图没有接入此 runner，也没有被真实模型测试。

第二次登记 pilot 已完成 39/39 局（15/39 成功，见 [pilot-report](pilot-report.md)）。MAP-08（假设表 vs 无表）、MAP-26（结构化恢复 vs 隐藏反馈）、MAP-30（完整历史/案卷 vs 最近 5 步）显示出可解释的条件差异；MAP-16、MAP-18、MAP-22 在当前条件下几乎无成功，属于测量敏感性不足或任务过难，扩展前须先修正测量设计。

若 pilot 完成，按以下 gate 决定是否另行立项；本文件不授权新增地图或 API episode：

1. 六图 Agent 输入/公开 trace 无隐藏真值泄漏，地图状态转移与 V4 原设计一致，真实 smoke usage 和账务链条完整。
2. 每个候选地图有明确可测能力、至少两个有解释力且混淆受控的条件、逐图指标和有效配对方案。
3. 对随机环境准备足够独立实例；固定场景不能把 seed 字段当成额外样本。
4. 每张图先完成运行时 Oracle 回放、失败/边界/确定性检查和独立求解器，再登记模型矩阵。
5. 单独冻结 episode 清单、模型/provider、prompts、资源 cap、价格版本、单一币种预算和未知计费停止条件，并在 paid 模式前重跑 offline gate。
6. Pilot 结果显示目标指标对预登记条件有足够敏感性，且错误能根据 trace 归因；若不满足，先修正测量设计，不批量接入余图。

新阶段须新增已审阅 spec 和预算登记。不得沿用或改写 V2 已关闭账本，也不得把本轮 MiMo observations 当成余图的能力结果。
