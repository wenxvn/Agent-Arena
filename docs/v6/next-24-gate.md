## 未满足项与阻塞

1. **测量敏感性不足**：真实结果表明当前多数实例对 `mimo-v2.6-flash` 要么过易要么过难，配对条件未产生可观测差异（见 pilot-report §3）。这是教程要求的“暂停并报告”触发条件。
2. **MAP-30 可玩性缺陷**：合法案卷条目 ID 未公开；已加入披露并验证残余失败属策略/流程，需人工重新设计取证流程。
3. **人工审阅未完成**：所有 V6 实例 `pending_human_review`。

## 建议

1. 人工审阅 V6 实例与本次结果，确认哪些实例需要重新定标（难度、条件、指标）。
2. 针对天花板图（08/22/26-free）**加大难度或提高成本**；针对地板图（18/26-recovery/30）**降低联合复杂度或补充公开结构信息**，并保持不泄漏裁判真值。
3. 在敏感性问题修正前，保持 `HOLD`，不新增地图、不扩大矩阵。
4. 任何后续付费矩阵都需要在新的离线门禁与预算登记下重新执行。
