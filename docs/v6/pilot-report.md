## 8. 能力效度分析（提纲 §8 五问，逐图）

1. **该图究竟测什么？哪些指标直接对应能力？** MAP-08 测证据驱动的诊断与信息增益（诊断准确率、测试次数、后验候选集大小）；MAP-16 测同步预约规划（容量/交换冲突、makespan 与最优差）；MAP-18 测联合时刻表改线与服务恢复（服务率、恢复时长）；MAP-22 测空间返程记忆（返程成功率、与最短返程差）；MAP-26 测故障诊断与反馈纠错（错换次数、剩余备件）；MAP-30 测长间隔证据召回与提交谨慎性（Q4 召回、事实引用准确率）。
2. **哪些失败是模型问题、接口问题、不可解问题、预算截尾？** 接口占 V6 修复前的主导（DCR-007…010），修复后 47 局无 schema 失败；模型策略失败见 MAP-18、MAP-26 recovery、MAP-22 `history5`；**不可解：无**（全部实例有成功 Oracle，MAP-18 构造解达最优服务率）；预算截尾见 MAP-18 的 action-limit 与 MAP-22 的 step-limit。
3. **对照条件除目标机制外是否等价？** 是：同实例共享初态/公开 Observation/预算；MAP-08 公开观察完全一致；MAP-22 仅记忆日志可差异（`test_paired_conditions_share_rule_outcomes`）；MAP-30 案卷只展开已记录证据。
4. **是否存在跨实例的稳定差异？样本数与局限？** 单次运行、每条件 1 局，**不足以断言稳定差异**；仅 MAP-22 L3 与 MAP-30 召回出现方向性差异，需重复验证。
5. **能否用更强模型 / 独立算法 / 简单启发式建立难度梯度？** 独立算法基线**已建立**（BFS/构造求解器给最优或下界）；更强模型基线**未验证**（只测 `mimo-v2.6-flash`）；简单启发式基线**未验证**。
