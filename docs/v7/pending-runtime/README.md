## 0. 为什么只有一个清单，而不是 24 个模板文件

## 2. 每张图接入时的统一门槛

按提纲 §5.2，**每次只实现一张**，且必须同时交付：

1. **规则冻结**：`map_spec.yaml` 的公开/私有字段、事件序、失败码逐条核对；与设计文档冲突先开 DCR，不改冻结规则。
2. **Oracle**：至少一条构造可行解 + 一条独立下界/最优证明（或明确写“只有构造解，无最优证明”）。
3. **手算指标**：卡片里的两条轨迹用真实 trace 重放，断言具体数值（含 N/A / CENSORED 分支）。
4. **边界与失败**：三个机制特有失败 + 两个边界必须在环境里可复现，不是纸面断言。
5. **无泄漏检查**：`private_fields` 不出现在 Observation、prompt、公开 trace；对照条件只差预登记机制。
6. **V7 extractor**：先在 `registry.py` 把该图的 `implemented` 从 `False` 改为 `True`，再在 `metrics/mapXX.py` 实现，并补 `tests/test_v7_map_metrics.py` 的 fixture。

未满足任一项，图保持 `runtime_status: design_only`、`metric_status: registered_design`。
