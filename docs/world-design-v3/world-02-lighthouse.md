# 02 灯塔：潮汐、航向与信号

## 机制图

公开潮历/航道标记 → 调整镜头与灯色 → 在正确潮相或雾潮交集发送有效序列 → 救援确认 → 在对应码头完成登船。

状态包括整数 tick、潮相/雾相、镜头方向、灯色、已确认信号阶段、信号过期点和救援确认。周期公开，错误信号不召来救援。

| ID | 关卡 | 设计与参考策略 | 主要边界 |
|---|---|---|---|
| LH-E | 点亮归航灯 | 查 shipping log，将镜头转 EAST，点灯并等 LOW，再发信号和去 east pier。潮位四相循环。 | 错方向或错潮相可重试；wait/inspect 推进相位。 |
| LH-M | 潮汐双信号 | 查手册与航图，先 WEST 白光确认；等 HIGH 再切红灯完成握手。 | 红先发不确认；公开白光确认状态在有效期内保留。 |
| LH-H | 迷雾里的三段信标 | 查三处航道/信号线索，设 WEST，发 SHORT-LONG；等到雾/潮交集再发末段并赴 dock。 | 前两段不要求窗口；错误符号与错时窗反馈不同且可恢复。 |

设计依据：研究提纲 §3。LH-H 的窗口交集以整数周期求解，并由公开 calendar 可计算。
