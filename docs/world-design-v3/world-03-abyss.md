# 03 深海站：压强、进水与取舍

## 机制图

查看水位/压差 → 关漏阀、抽排或分配泵 → 更新水量/压力 → 阈值控制通行与安全 → 携带研究目标上浮。

核心变量为每舱整数水位/压强、阀门、泵状态和有限泵能。水位、变化率和压差阈值公开；不同于飞船隔舱，核心操作是流体平衡与跨舱资源分配。

| ID | 关卡 | 设计与参考策略 | 主要边界 |
|---|---|---|---|
| AB-E | 止住一舱水 | 先到 valve room 关漏，再到 pump room 抽水，最后在水位安全时乘 lift。初始水位 4、漏水 +1/tick、每次抽排 -3。 | 漏阀未关时抽水后会回涨；lift 对水位 >2 拒绝；水位 10 失败。 |
| AB-M | 平衡两侧压力 | 从 west 取样，去 east 分次升压至与 west 差不超过 1，再开 equalizer gate 上浮。压强 5/2，每次泵 +1。 | 差值 2 拒绝开门；超压拒绝；缺样本不算完整成功。 |
| AB-H | 弃舱保核心 | 关 greenhouse 溢流门，取数据盘，把仅有三次泵能分配给 control/machine 核心舱后上浮；温室允许失守。 | 泵给温室会危及核心；漏门未关仍渗水；数据遗失只算 partial。 |

设计依据：研究提纲 §4。AB-E 的操作 tick 次序下水位 4→5 后关漏、再抽至 2，可在危险阈值前到 lift；AB-M 无周期漏水；AB-H 的三次泵分配仍需状态空间检查。
