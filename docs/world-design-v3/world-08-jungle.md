# 08 丛林遗迹：地标导航与环境地图变化

## 机制图

局部地标给出方向约束 → Agent 形成已知路线 → 藤门或水位改变当前连边 → 依据新 Observation 重定位 → 取任务物并沿安全路线回营。

完整邻接表只在 Environment 与测试中存在；Observation 只提供当前可行出口和近处标志。动态边改变可达性，但不能把已进入的房间变成不存在节点或产生永久软锁。

| ID | 关卡 | 设计与参考策略 | 主要边界 |
|---|---|---|---|
| JU-E | 三棵标记树 | 从 scout note 识别红树通向古碑，取 ruin notes 并回 camp 上报。 | 蓝/白支路有不同反馈；错路可原路返回；未取物不能上报。 |
| JU-M | 会转向的藤门 | 调查 rune marker 后将 turntable 设 EAST，走 east path 进遗迹并开返程捷径。 | NORTH/EAST 连边互斥；方向更新不改变历史 Trace；保留离开安全路。 |
| JU-H | 风暴重绘路径 | 依据六相水位周期，在河道或稳定山脊到 stone circle；按 OAK-FERN-VINE 解锁 altar 与返程门。 | 高水拒绝河道但不封死全局路径；错误序列可重试；允许安全返程。 |

设计依据：研究提纲 §9。河道状态只在进入/离开受影响连接时检查，潮相更新不能把 Agent 悬空移出地图。
