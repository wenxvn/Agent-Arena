# 09 月球基地：舱外氧气与日照能源预算

## 机制图

出舱前查看氧气、距离与目标规则 → 估算单程/返程余量 → 在室外消耗氧气并做维修/救援 → 需要时补氧或等日照 → 人和目标安全回 habitat。

氧气只在 outdoor action tick 消耗；进入/离开室外的移动计入。无 suit 不可出舱，补氧消耗有限 reserve；成功要求目标完成且人员回舱。

| ID | 关卡 | 设计与参考策略 | 主要边界 |
|---|---|---|---|
| LU-E | 第一趟舱外行走 | 在 storage 取 patch kit，穿 suit，循环出舱修 panel，再进气闸回 habitat。 | suit 必需；O2 不得为负；修完未回舱不算完成。 |
| LU-M | 日照与电池 | 取 battery module，按公开六相太阳窗口充三单位，必要时补氧后装入通信塔并返舱。 | 阴影拒绝充电；等待也消耗室外氧气；reserve 有限。 |
| LU-H | 双 EVA 救援 | 第一趟修 mast，回舱补氧；第二趟找到队员并 escort 返回，分别核对双方余氧。 | mast 未修不完整；不能远程 escort；同伴只在公开位置允许有限应急补氧。 |

设计依据：研究提纲 §10。LU-M 的日照等待以及 LU-H 的双人氧气均须离散模拟确认返回余量。
