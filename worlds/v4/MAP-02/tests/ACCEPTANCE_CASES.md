# MAP-02 Phase 1 测试用例草案

当前目录只记录未来环境实现的逐图验收要求，不含已执行测试。

1. 第 3 个环境动作后无泄漏，第 4 个动作直接效果结算完才触发 L1 泄漏；语义拒绝动作仍推进序号。
2. 在第 4 步关闭 C-L1，泄漏仍开始但不会向 R1 扩散；尝试重开应返回不可逆闸门拒绝码。
3. 泄漏后未隔离，连续两次动作后以 `NAV_CORE_FLOODED` 终止；先隔离则扩散计数停止。
4. 两个 oracle 各自重置后回放，最终目标状态和逐步 hash 固定。
5. `crew_first` 在第 8 个泄漏后 tick进入 R2应成功；在该边界结束时仍未到 R2则以 `CREW_PRESSURE_LOST` 失败。
6. 第 20 tick前完成两个目标成功；第 20 tick仅完成一个目标则以 `GLOBAL_DEADLINE` 失败。
7. 闸门关闭后只能通过 C-X-L2 外环救援；修理包只在 R1 且仅有一个，封存导航核时消耗一次。
8. 不可借 Observation 读取 E 的隐藏目标或未来泄漏事件。
9. 事件前 Observation 不序列化动作序号、扩散时钟、任何 oracle 轨迹或对照组标签。
