# MAP-05 Phase 1 测试用例草案

以下均为环境实现后的待运行规则测试，不代表测试已执行。

1. Reset 时位置为 C、tick=0、供电为空、所有校准进度为 0。
2. 航表读取只在 C 有效且耗 1 tick；窗口 R `[15,18]`、B `[22,25]`、W `[29,35]` 均包含起止端点。
3. 仅能在 C 切换供电；切换后同时连接两塔必须被拒绝并按规则消耗时间。
4. C-R、C-B、C-W 单次移动分别耗 1、2、3 tick；没有跨越两个节点的移动动作。
5. 校准阶段只能在当前位置等于供电目标时递增；完成后的进度在断电及重新供电后保持。
6. 信号必须在目标塔、该塔已完成两阶段校准且当前接电；发射只可成功一次。
7. 发射动作完成于窗口开始端点和结束端点时成功；完成 tick 在端点之外时返回明确错误；未发送信号在截止 tick 仍未发出则失败。
8. 若多 tick 移动跨过未完成信号的截止，结束移动时先处理移动结果，再因截止失败；终态不得接收后续动作。
9. 重放 `near_first` 与 `far_first_prep`，逐步 tick、位置、供电、校准、发射和状态 hash 与手写期望一致。
10. 重放 F01–F03，失败原因统一为 `SIGNAL_WINDOW_MISSED`，`failed_station` 分别对应 R、R、B。
11. `oracle_trace` 和失败归因标签不出现在普通 Observation、prompt 或 agent trace。
