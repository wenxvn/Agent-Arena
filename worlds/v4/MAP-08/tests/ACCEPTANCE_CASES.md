# MAP-08 Phase 1 测试用例草案

这些是环境实现后执行的确定性规则用例，不是已运行的测试。

1. Reset 为位置 A、核心水位1.0、密封剂1份，且 B/D/F 三种种子的普通初始 observation 完全一致。
2. X 只能在 X 测试，Y 只能在 Y 测试；每次测试耗2 tick，返回符合表格的确定信号。
3. 同一站重复测试读数不变，且仍耗2 tick；不额外扣密封剂、不产生随机新读数。
4. 图中六舱环和四条测试台边外无其他可走边；每个 move 恰走一个 edge、耗1 tick。
5. 每个未修复 tick 核心水位 +0.5；7.0可继续，超过7.0立刻失败。
6. 正确修复耗1 tick并在结束时封漏；最后 tick 的泄漏先结算，所以 tick12修复使水位7.0成功。
7. 错误修复耗4 tick，消耗唯一密封剂并以 `SEALANT_MISUSED` 失败；不能用更多密封剂重试。
8. 两顺序的正确轨迹以及 F01–F03 的签名、位置、tick、水位与 `oracle_trace.jsonl` 一致。
9. 在均匀先验下 X/Y 单测的信息增益均为约0.9183 bit；B-heavy/D-heavy 组的首测收益排序发生预期改变。
10. seed→真漏映射、评分标签和 Oracle 轨迹不进入 Agent 的 Observation、prompt 或 trace。
