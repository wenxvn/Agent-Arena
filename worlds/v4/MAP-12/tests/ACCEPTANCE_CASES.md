# MAP-12 环境实现后验收用例

以下是未来实现时的规则用例清单，当前未运行 pytest。

1. Reset：seed0、30日、燃料40@E、食物30@H、零件8@S，炉开启、控制器在线，其他节点库存为0。
2. 拓扑：H-E、E-G、G-S、S-L、H-S、G-L 六条无向边；每次转运必须提交 canonical edge id 及匹配的 from/to 端点，禁止跨边传送。
3. 每日最多2个人力动作；动作发生在日结算前，同日转运可以供当日日配给使用。
4. 磨损仅在日7/14/21/28日初发生。该日 G/L 先离线；E有2零件时维修占1动作并恢复本日控制器，否则保持离线并归零研究/温室连续串。
5. 供暖每日独立从E燃料库扣1；关闭或无燃料记热欠供，正好1燃料安全扣到0，连续欠供第2日失败。
6. 种下批次与启动供能均耗1槽；只有在线控制器下已种且已供能的日结算才额外耗1燃料并增加温室连续天数。第三日末增加5食物并自动关闭；未满足条件的日将连续计数清0。
7. H每日在分配时库存大于0才供给1份；供给到0属于正常，下一日开始断粮欠供第1日，连续第二日触发 `FOOD_SHORTAGE_STREAK`。
8. L的研究动作受控制器约束；连续研究第三日末才结算3分并清零，任何中断清空连续数。12个连续日得到12分。
9. 纸面计划 `research_priority`：30行逐日 Oracle，day30应为 fuel7、food_H5、research12、零件维修8、欠供0、成功；逐日动作不得超过2。
10. 纸面计划 `safety_buffer`：30行逐日 Oracle，day30应为 fuel4、food_H10、research12、零件维修8、欠供0、成功。
11. F01 供暖关闭两日于day2失败；F02 导出口粮15日后从day16起欠供、day17失败；F03 仅出现两日研究串，day30以 `RESEARCH_TARGET_MISSED` 失败。
12. 每种库存转运守恒；燃料40 = 当前燃料 + 供暖累计 + 温室累计；食物总量30 + 收成 - 日配；零件8 = 三地库存 + 已维修用量。
13. 两个成功计划及三条失败计划各自使用相同 seed/actions 重置重放时应生成相同的逐日状态与终止码；环境阶段才比较状态 hash。
