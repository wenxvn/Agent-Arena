# MAP-14｜说谎的祭司

状态：`DESIGN_COMPLETE_PENDING_RUNTIME`。这是一个有限真值逻辑关卡。三名祭司不是自由对话 NPC：每人只持两条固定命题，提问只返回 Yes/No；恰有一名祭司在任何命题上如实回答，另外两人永远反报。玩家需从档案、答案与唯一诚实者假设中找出门锁配置。

## 拓扑与锁型

移动图严格为 `P—A—O—J`：P 祭司厅，A 档案室，O 供奉/比对厅，J 审判门。P-J 封闭，四条有效边 `P_A`、`A_O`、`O_J` 均为1 tick；不能从 P 直接审门。三种配置是 `A=日轮锁`、`B=月牙锁`、`C=星井锁`。本次固定 seed0 的真实配置为 B，真实诚实者为乙；两者在初始 Observation 中都私有。

## 固定命题与回答语义

六条命题在 P 的石牌上公开，分别由三人各持两条；公开牌面不暴露真假：

| 祭司 | 命题 | 命题在哪些配置下为真 |
|---|---|---|
| 甲 | A1：当前为日轮锁 | {A} |
| 甲 | A2：当前为月牙锁 | {B} |
| 乙 | B1：当前不是星井锁 | {A,B} |
| 乙 | B2：当前不是月牙锁 | {A,C} |
| 丙 | C1：当前为星井锁 | {C} |
| 丙 | C2：当前不是日轮锁 | {B,C} |

`ask(claim_id)` 的意思是问持牌祭司“这条命题为真吗？”诚实者回答命题真值；两个说谎者回答其反值。真实世界为配置 B、乙诚实，因此 A1/A2/B1/B2/C1/C2 的回答分别为 `是、否、是、否、是、否`。每条牌只能问一次，整局最多问4条；答案以结构化布尔值和原问题 ID 记入账本，不生成自由文本。

## 机器可查的唯一解

候选隐藏状态共9种（3种锁型 × 3名可能诚实者）。固定系统问序 A1、A2、B1、B2 对9种状态产生不同的4位回答码；故四问足以唯一识别锁型与诚实者。`planning/truth_table_audit.py` 会展开九行真值表并检查码唯一。

A 室档案是第二条解题路径的额外证据：“星井锁C从未安装在当前门上”，将锁型候选由三种收至 A/B，隐藏状态由9种收至6种。查档案路线固定问 A1、B1、B2，真实回包 `是、是、否`，在剩余6态中唯一指向 B/乙。若不查档案，可在 P 使用同一审计脚本生成的自适应决策树；本次真实状态在 A1=是、A2=否、B1=是后已唯一收敛，最坏路径不超过4问。

O 室提供空白比对台。`compare_evidence` 在此记录玩家的 `(锁型候选, 诚实者候选, 支持证据ID)`，只回执“已封存”，不检查对错也不给候选数。J 室 `submit_configuration` 只以锁型决定是否开门，和提纲的胜负谓词一致；诚实者推断正确性单独进入逻辑一致性评分。错误锁型提交两次即失败。这样问话辨真值、比对形成可追溯假设、J 提交承担最终验证，各室功能不重叠。

## 两条手写成功路线

1. **档案先行**：P→A读档→P；问 A1/B1/B2；再走 P→A→O 写下 B/乙及三条答复证据；O→J 提交B。11 tick、3问、候选9→6→1。
2. **无档案自适应**：在P依决策树问A1、A2、B1，按 `是/否/是` 分支锁定B/乙；P→A→O登记假设与三问证据；O→J提交B。8 tick、3问，未使用档案；其他隐藏状态分支最坏4问。

两路得到同一正确配置，但信息来源、查询顺序和移动成本不同。测量提问数、行动tick、档案使用、唯一诚实者识别与锁型正确率。

## 失败与边界

`failure_traces/cases.yaml` 三条失败均以真实 B/乙情境回放固定答案：把甲的反报误当真、读到“C未安装”却仍提交C、或用信息不足的四问子集把仍兼容的 A/甲候选误当唯一解。每条都消耗不超过4问，给出 `compare_evidence` 记录，再提交两个错误配置，第二次错误在同 tick 终止。

边界：首次错配仍允许第二次提交；第二次错误立即失败；若一错后正确提交则成功；四问用尽不自动失败但第5问被拒且不推进 tick；档案缺读时不得在 Observation 中出现其内容；证据比对只封存玩家输入，不充当答案Oracle；固定 seed0 重放同问序/路线时每个答复、计数和终止码一致。

## 设计边界

- 保留四节点线性路径及 P-J 关闭；A/O/J 各承担档案、记录比对、开门验证功能。
- 祭司每人的两条具体命题、真值函数和说谎规则静态固定，不调用模型生成语句。
- 档案事实和六条命题文字可公开；真实锁型、诚实者身份、答案真值表行号与裁判标签不出现在初始观察。
- `truth_table_audit.json`、Oracle 与失败轨迹是裁判侧设计证据，不能放进 Observation、prompt 或 Episode Trace。
- 当前只有真值表枚举和手写策略纸面回放，没有环境或 Agent 运行结果。
