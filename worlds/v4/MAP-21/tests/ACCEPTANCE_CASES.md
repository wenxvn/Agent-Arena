# MAP-21 运行时实现后验收用例

这些用例用于后续环境实现验收。本设计阶段只执行MAP21专属决策审计，不运行pytest。

1. Reset seed0时玩家在O、elapsed为0；规则先验为喷发tick12/16/20对应0.2/0.5/0.3，普通Observation没有喷发时刻或倒计时字段。
2. O-R、R-W、W-S、S-E、O-E边耗时分别1、2、2、2、6tick；任一多tick移动中不能改道，反向边耗时相同。
3. 在O执行唯一一次测量，耗满2tick后才返回一个早/晚报告；仪器未返回前不得看到结果。测量不可重用，也不能在其他节点执行。
4. 早报似然按真值依次为0.8/0.3/0.1，晚报为0.2/0.7/0.9；同seed报告重复一致，跨真值统计符合配置的采样机制。
5. 早报后验应为`[8/17,15/34,3/34]`，晚报为`[2/33,35/66,9/22]`；两个结果都保留12/16/20三个可能真值，不可直接显示真值。
6. R表层灰样耗1tick、值5；W层理芯耗5tick、未加固12分；S同位素芯耗6tick、未加固40分。每局最多成功带出一件样品。
7. 在W或S加固包装耗1tick、每局最多一次，只把同节点样品分别提高到20或50分；加固不改变喷发、移动耗时或别处样品分值。
8. 每个时间动作按内部tick推进；若事件在动作中途到达且人不在E则立即失败、停止动作、所有科研数据记0。
9. 多tick边的最终tick先解析到达。如果该次到达为E且刚好等于喷发tick12，则安全撤离成功；差一个tick在E外仍触发`FATAL_ERUPTION`。
10. O-E盲撤计划tick6抵达，对12/16/20三种真值全得100分。O-R取低样再经主线撤离计划tick8抵达、全得105分。
11. 不测量取W中样、不加固：路径耗时12，T=12在同tick入E成功并得112分；加固后时间变13，T=12在S或途中失败并得0。
12. 测量分支策略：早报取R低样，tick10抵E，三个真值均得107；晚报取W加固中样，T=12失败、T=16/20得122；按先验和似然求策略期望112.02、存活率0.96、期望科研16.02。
13. 深样冒险路线：S样加固后tick14抵E；T=12失败，T=16/20得150；策略期望120、存活率0.8，日志不得只汇报晚喷发seed的150分。
14. F01/F02/F03重放分别在T=12的S、晚报分支的W-S途中、忽略早报的S触发死亡，失败时样品和测量分均为0。
15. 期望效用必须对每种隐藏时刻及其早/晚似然联合加权；测量信息增益按1.029653−0.891655约为0.137998 nats，不能根据一次seed结果宣称准确率或风险已消除。
16. 公共Trace/Observation可以包含经过tick、当前位置或在途边、报告、由报告算出的后验、本地可见样品与终止分数；不能包含隐藏喷发tick、随机抽样值、未揭示的测量结果或离线评分私表。
17. seed0相同动作重复重放时，每tick公开Observation、报告、后验、位置、终止原因、得分和Oracle字节完全相同；静态夹具中的隐藏时刻和随机值不返回Agent。
