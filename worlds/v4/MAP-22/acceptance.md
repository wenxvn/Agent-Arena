# MAP-22 设计验收

状态：`DESIGN_COMPLETE_PENDING_RUNTIME`。MAP22使用一张人工固定的12节点、15边森林遗迹图；粗形相近的四个三叉路标有各自可观察的细部标记。运行时只给当前路标和出口方位，图关系必须通过实际行走后写入有限外部记忆。专属拓扑审计器核对每条双向边、方向、路标、访问路线、路径冗余、全图回访、步数边界、三类失败和18步公共Oracle。当前没有环境或Agent运行结果。

## 逐图设计核对

- [x] 固定A/B/C/D/E/F/G/H/I/J/K/L十二节点拓扑，15条无向边、循环秩4；逐边校验路标方位和反向出口互为一致。
- [x] 为十二个节点手工分别指定粗形和唯一检查标记。B/E/H/K都呈三叉桩，分别以红斜缺口、东侧双根、鞍下双刻、西脚苔楔区分。
- [x] 每个当前Observation只给本节点粗形/已检查标记和出口方位；不显示邻居标记、邻居身份、未访问出口、全局表或返程导航。
- [x] `observe_signpost`只检查本地路标；外部记忆最多32条，只能记录已检查节点或最近实际经过的边，既不自动生成也不接收完整地图请求。
- [x] `return_to_camp`仅把目标切换为营地，不移动、不选路；实际成功仍要求经过L后由Agent逐边返回A，移动不超过30步。
- [x] 解析A到L最短路唯一为A-C-F-I-L，4步；另有内部节点不相交的A-B-E-H-K-L，5步；完整地图最短往返上界8步、循环秩4。
- [x] 手写无记忆局部优先策略：第6步后进入J-K摆荡，步满30时在J，未到L；这是一种明确可重放基线，不宣称所有无记忆策略均失败。
- [x] 手写图记忆全边巡回`A-B-D-G-J-K-H-E-B-E-F-I-L-K-H-I-F-C-A`：18步访问12节点、15条边；重复节点到访7次、重复边3次；L在第12步，A在第18步；27条自写事实完整覆盖节点和边。
- [x] 手写MAP22专属DFS全边边界路线：每条独立边恰走两次，访问L后在第30步回A成功；另写31步计划在第30步停于C、失败。
- [x] F01无笔记罗盘策略陷入J/K；F02在L后误记I北口并陷入I-H-K-L环；F03先访问L但反复走冗余边，超出返程上限。
- [x] B01精确30步成功、B02必须第31步返营失败、B03当前K只公开W/N/S方位并拒绝完整邻接请求。
- [x] 公共Oracle逐步记录18次行走、到当前路标才检查唯一标记、只写已走边；seed0无随机事件，连续两次生成逐字节一致。
