# MAP-22 运行时实现后验收用例

以下用例用于未来环境开发后的验收。本设计阶段只执行MAP22手工拓扑/路线审计，不运行pytest。

1. Reset seed0：当前位置A、步数0、目标牌为三重黑弧遗迹门；seed不改变这张图的固定边、方位或路牌特征。
2. 普通Observation只显示当前路口粗形与当前出口方位；邻接节点标识、未到达节点、全局邻接表和自动返程路径均不可见。
3. `observe_signpost`只看当前路牌的独特标记。B/E/H/K的粗形都为三叉桩，只有细看红斜刻、东侧双根、鞍下横刻、西脚苔楔才可正确区分。
4. 每个节点出口方位必须与固定表一致：A NE/SE；B SW/NE/E；C NW/E；D SW/E；E W/S/E；F W/N/NE；G W/E；H W/S/E；I SW/N/E；J W/S；K W/N/S；L W/N。
5. 只允许选择当前节点可见的方位。非法方位、请求邻居标识或请求完整邻接表不得移动、增加步数或填入记忆。
6. 每次走一个实际相邻边恰增加1步；观察、记忆、检查目标、返营意图不增加移动步数。走边途中不允许提前抵达、改向或减少成本。
7. `write_memory`最多保存32条；节点卡只来自当前已检查路牌，边卡只来自最近确已走过的边及两端检查结果。不能写未走过边的端点或未来节点数据。
8. 当前记忆笔记可由Agent查阅，但笔记必须仅包含先前写入的证据；环境不自动把全图复制进笔记，不接受完整邻接表读取请求。
9. `return_to_camp`只把活动目标设为营地标记。当前位置不改变，Agent仍需逐边选择方向，不生成下一步路由。
10. 每一步进入目标路牌L时，内部任务状态记为已到遗迹；只有之后回到A且移动步数不超过30才成功。
11. 离线完整图最短A-L路为唯一的A-C-F-I-L，长4；原路返回共8步。另一条内部节点不相交的A-B-E-H-K-L长5，验证存在真实路径冗余。
12. 外部记忆巡回`A-B-D-G-J-K-H-E-B-E-F-I-L-K-H-I-F-C-A`需18步，覆盖12个节点与15条边；B-E、F-I、H-K各被重复走一次；L在第12步，最终回A成功。
13. 外部图日志最多写12张节点卡和15张边卡，共27条，完整图只在实际走遍所有边后逐渐成为Agent笔记，不出现在初始Observation。
14. 固定方位贪心基线A-B-D-G-J-K后会在J/K间反复走，到第30步仍在J、未达L并失败；日志正确统计访问6节点、5条唯一边、25次重复边移动。
15. F02带错记忆到达L后从I误走N至H，再沿H-K-L环重复；第30步在H仍未回A。
16. DFS边界路线遍历全15边各两次，30步内先访问L并恰回A，最后一步成功；第30步未满足目标与回营条件则立即失败，第31步动作不得接收。
17. seed0相同外部记忆巡回连续重放两次，逐行本地路标、方向、记忆日志、目标状态、步数及Oracle字节一致。
18. 完整地图最短路只作为离线上界，不允许通过游戏Action取得；公开Oracle和运行Observation不得出现内部节点字母、邻居节点名或未观察过的特征。
