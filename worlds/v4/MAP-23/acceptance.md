# MAP-23 设计验收

状态：`DESIGN_COMPLETE_PENDING_RUNTIME`。MAP23把真入口不确定性、三处不同强度的局部侦察、双向路费、假入口调查和一次性营地补给箱放在同一补给账上。三变体不是同一线索表的地点重命名：每个真入口都有一整行重新编排的N/R/H信号。专属信息价值审计器对每变体逐动作结算侦察、移动、错误调查和补给缓存，并枚举全部3种真值。当前没有环境、Agent或模型运行结果。
