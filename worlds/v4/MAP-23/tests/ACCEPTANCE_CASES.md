# MAP-23 运行时实现后验收用例

这些是环境实现后的验收规格。本设计阶段只运行MAP23专属静态信息/补给审计，不运行pytest。

1. Reset公开A、14/14补给、N/R/H本地出入口及X/Y/Z候选名；不得公开variant ID、真入口、未侦察站信号或未来调查结果。
2. A-N/N-X/N-Y/A-R/R-Y/R-Z/A-H移动成本依次1/1/2/2/1/2/2；边反向移动成本相同，非法非邻接移动不扣补给。
3. N、R、H分别每局只能侦察一次，成功侦察各扣2补给；余额不足2时侦察原子拒绝，不返回线索、不改线索记录。
4. N线索只可能将X/Y或Z作为候选；R线索只可能将X或Y/Z作为候选；H远眺信号只对应X、Y、Z其中一个。每个报告都至少排除一个入口。
5. 真值X变体私表必须是N=`STONE_SPLIT`、R=`WATER_UPSTREAM_SINK`、H=`RIDGE_NORTH_WHITE_MARK`；真值Y为N=`STONE_SPLIT`、R=`WATER_TWIN_RIPPLES`、H=`RIDGE_CENTER_AMBER_MARK`；真值Z为N=`STONE_THREE_RINGS`、R=`WATER_TWIN_RIPPLES`、H=`RIDGE_LOW_BLACK_MARK`。
6. 变体选择必须同时切换隐藏真入口和N/R/H信号。比如从Z变X时三条信号都变；任何真值下三站报告的候选集合都必须包含真入口。
7. 调查X/Y/Z分别扣3/2/3补给；错误入口被公开标记为false并不能重复调查；未搜过的其他入口状态保持隐藏。
8. 调查为真且扣费后余额大于0才以`TRUE_ENTRANCE_FOUND`成功；真入口调查后余额恰0返回`SUPPLY_MUST_REMAIN_POSITIVE`；假入口调查后余额0返回`SUPPLY_DEPLETED`。
9. A的缓存最多一次，只在库存小于14时将库存补满到14；不能将14再增加到28，不能在其他节点调用，且补给动作不走路、不消耗库存。
10. `mark(X/Y/Z)`只保存Agent标记，可被覆盖，不调用隐藏真值、不扣库存，也不替代真实`investigate`。
11. 山脊精确信号政策在X/Y/Z三变体应分别剩9/9/7，并都只调查一个入口；三结果期望库存25/3。
12. 北林石刻政策应依次核对X/Y/Z三变体，结余7/2/3；河谷水纹政策结余9/7/1；低成本试探政策结余9/4/7，其中Z路线必须在A用缓存后再去R-Z。
13. 侦察信息增益以等权先验计算：N/R单次`H(2/3,1/3)=0.91830` bits，H单次`log2(3)=1.58496` bits；走到站点的补给计入信息成本。
14. F01/F02/F03按隐藏变体和逐动作库存重放，分别在错误搜索耗尽、假Z无路可返、提早用缓存后耗尽；不得把假调查写成发现真入口。
15. B01 `Z,supply=4`调查后余额1成功；B02 `Z,supply=3`调查后余额0失败，证明成功谓词是严格`>0`。
16. 相同seed0和相同路线重复重放时，每条局部连接、侦察信号、标记、错误入口、补给余额和终止Oracle完全相同；seed0的私有Z真值及表格不返回Agent。
